# THE CITY OF VAEL

Local frontend kit for the City: five live Rooms, City shell, Community, Trust, and a structural Extended VAEL demo. Data stays in this browser. This is not a shared City and not a production backend.

```bash
npm install
npm run dev        # http://localhost:5173/
npm run typecheck
npm test
npm run build
```

There is no lint script. Design-system gallery: `/design-system`.

See `docs/` — especially `VAEL_FINAL_QA.md` and `VAEL_HANDOFF.md`.
